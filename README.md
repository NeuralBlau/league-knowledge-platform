# League Knowledge Platform

Knowledge ingestion and retrieval platform for a voice-first League of Legends AI coach.

## Status

Planning / V1

## Planned Scope

- Curated League of Legends knowledge ingestion
- Bronze / Silver / Gold data pipeline
- Transcript processing and chunking
- Metadata enrichment
- Embeddings
- Hybrid retrieval with Azure AI Search

This repository is part of the larger League AI Coach project.
